**SQL Data Cleaning Project**
A data cleaning project completed as part of my SQL learning journey, based on a project by Alex The Analyst.

**Project Overview**
The goal of this project was to clean and prepare a dataset
containing information about company layoffs for further analysis.
The project focuses on identifying and correcting common data quality issues using SQL.

This project was based on Alex The Analyst's SQL Data Cleaning project. 
I followed the tutorial while writing and adapting the queries myself and used the project 
to practice SQL data cleaning techniques.
'layoffs.csv' is raw data I downloaded from Alex's GitHub
